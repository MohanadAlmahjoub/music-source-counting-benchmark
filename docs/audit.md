# Benchmark audit

## Reproduction check

An independent calculation reconstructed all 46,656 synthetic frames from the identifiers in [the decision table](../results/robustness/trials.csv.gz). It whitened the sample covariance as $L^{-1} R L^{-H}$ instead of whitening each snapshot, computed MDL from explicit arithmetic and geometric means, and applied the tail rule directly to the quantized median. All 559,872 raw and whitened decisions matched. An independent aggregation also matched all 549 rows of [cell-level counts and paired differences](../results/robustness/cells.csv). The reproduction check verifies the implementation for these generated inputs.

Run the independent verifier from the repository root after installing [the CPU dependencies](../requirements.txt).

```sh
python tools/verify_robustness.py
```

Pass `--fixtures` to check a regenerated directory containing `trials.csv.gz` and `cells.csv`. The verifier checks decisions and summary counts. The uncertainty audit below addresses interval interpretation.

Each comparison uses the same frame and spectrum for every count rule. Raw and whitened decisions use the same frame, and the Cholesky factor comes from a separate noise-only draw with its own seed stream. Each factor is reused across 24 frames per cell and across the nine cells of a scenario. This is why each cell has 72 independent calibration clusters, with 1,728 decisions, and why cross-cell comparisons should preserve the shared calibration identity.

## Uncertainty and the stop decision

The two-sided 95% intervals in the robustness table are **pointwise**. The cluster bootstrap resamples calibration batches within seed strata, preserving the paired decisions within each frame. Treating all frames as independent would ignore dependence through the shared whitening transform. The fixed seeds define the simulation strata. The estimates describe the specified synthetic distributions and the equal weighting of the published grid.

Percentile bootstrap intervals can collapse at all-success, all-failure, or constant paired-difference endpoints because resampling cannot generate an unobserved event. The table uses conservative event bounds at those endpoints and contains no equal-endpoint intervals. For zero observed events, the upper limit is $1-0.025^{1/72}=4.9944\%$, using the probability of any event in a calibration cluster to bound the expected per-frame rate. Sparse nonzero-event intervals still warrant caution. For example, the matched correlated Q12 case had one false alarm in one calibration. Its observed per-frame rate was 0.058%, while the exact two-sided 95% interval for the probability of any alarm in a calibration had an upper endpoint of 7.50% under the independent, common-distribution cluster model.

Individual cell intervals do not jointly certify the operating range. Even for only three noise-only scenarios, a two-sided Bonferroni adjustment would raise the 72-cluster zero-event upper bound to 6.43%. The reported 99% per-cell agreement threshold is a point-estimate check. A perfect cell has a conservative pointwise agreement lower bound of 95.01%, so perfect observed agreement alone cannot establish a population agreement rate above 99%. The overall 99.94% agreement describes quantization parity and can be high even when both variants choose the wrong count. [NIST on simultaneous comparisons](https://www.itl.nist.gov/div898/handbook/prc/section4/prc473.htm)

The drift failure is large enough to survive a more conservative calculation. Q12 false alarms occurred in 804 of 1,728 frames and all 72 calibration clusters after whitening at a calibration correlation of 0.20 and test correlation of 0.35. A one-sided 95% Hoeffding lower bound across the independent bounded cluster proportions is $804/1728-\sqrt{\log(20)/(2\times72)}=32.10\%$, above the 5% project gate. The capped MDL comparator had 10 alarms in 1,728 frames under the same drift and transform. Across the equally weighted source-present cells, Q12 had 721 wins and 703 losses against capped MDL. The net +0.043 percentage points can conceal substantial cell-level regressions, and its interval includes zero. [Hoeffding, 1963](https://doi.org/10.1080/01621459.1963.10500830)

## Baseline and numerical scope

- **AMD proxy.** The tutorial compares squared norms of the final Jacobi columns against 5% of the first column, and encodes an eight-count result as an empty spectrum. The count experiments use sorted exact covariance eigenvalues and map that sentinel to zero. This comparison isolates the threshold rule on an ideal spectrum. The tutorial graph's approximate four-sweep QR/Jacobi output, precision, column order, and angle finder are outside that proxy. [AMD tutorial](https://github.com/Xilinx/Vitis-Tutorials/blob/2026.1/AI_Engine_Development/AIE/Design_Tutorials/18-MUSIC-Algorithm/README.md) · [AMD count implementation](https://github.com/Xilinx/Vitis-Tutorials/blob/2026.1/AI_Engine_Development/AIE/Design_Tutorials/18-MUSIC-Algorithm/aie/svd/svd.cpp#L71-L99)
- **Capped comparison.** Q12 checks the three largest eigenvalues. The capped AMD proxy clips its decoded count to three. Capped MDL minimizes its criterion over orders 0–3. This gives a common output range while retaining different estimation rules. The results include the original AMD proxy and MDL alongside the capped variants. MDL uses a white-noise model, so colored residual noise after imperfect whitening can still affect it. [Wax and Kailath](https://doi.org/10.1109/TASSP.1985.1164557)
- **Fixed-point boundary.** The middle two of the four smallest descending eigenvalues are at zero-based indices 5 and 6. The integer rule $8q_i > 9(q_5 + q_6)$ is algebraically equivalent to comparing against 2.25 times their quantized median. Normalizing by the largest eigenvalue and rounding to 12-bit codes is still performed in software, and the comparison needs up to 17 unsigned bits. The estimator tests count parity with quantized inputs. Hardware integration would need to specify normalization, rounding, degenerate-input behavior, and the interface protocol.
- **Covariance convention.** With each snapshot stored as an unconjugated row, the angle pipeline uses $X^T\overline{X}/n$ for the sensor covariance. The conjugate convention in the count-only pilot gives the same eigenvalues. Its eigenvectors would require the corresponding steering-vector convention. In a whitened angle pipeline, the snapshots and steering vectors must receive the same spatial transform.
- **Operating conditions.** The generated data use zero-mean Gaussian noise, narrowband independent sources, a known half-wavelength array, and clean calibration. SNR is the strongest source's nominal per-sensor power divided by unit pre-whitening noise variance. Power rank follows angle order when sources have unequal powers. The study does not resolve sensitivity to coherent sources, calibration contamination, sensor mismatch, or other noise models.

The CPU profile uses 1% trace-target covariance shrinkage, while the robustness experiment uses 0.1% additive diagonal loading. The SVD reference checks agreement with the CPU implementation using the same steering grid and peak-selection rule. Agreement with that reference measures numerical consistency. The fixed-point sweep separately compares direction estimates against the simulated emitter angles. Its projection sweep takes the floating-point MDL count and subspace as inputs, so count agreement is guaranteed there. The two fixed-point sweeps isolate individual kernels, and the error after chaining them would need a separate check.

CPU timings are local software measurements. CUDA results cover the specified stages, residency, transfer path, and batch sizes. The GPU modes are timed in separate runs, so differences between their sample medians include run-to-run timing variation. Estimator agreement, floating-point timing, and an arithmetic operation count do not establish FPGA timing, area, energy, or board throughput.
